# Salt All The Things 0.0.6

## Highlights

- Adds the authenticated persistence and API foundation for reusable guest records and many-to-many episode appearances.

## Fixes/Changes

- Adds private guest records, conflict-safe guest-to-show links, lifecycle controls, derived appearance statistics, and backward-compatible authenticated import/export fields.

## Validation

- Adds focused contract, API, persistence, lifecycle, concurrency, privacy, import/export, and reversible-migration tests for the Guest Bank foundation.
- Extends the frontend storage contract and isolated-environment deployment smoke checks for guest records and assignments.
- Keeps the complete pull-request suite on one asyncio loop so isolated PostgreSQL connections are closed deterministically during validation.

## Deployment/Migrations

- Adds reversible Alembic revision `0009` for private guest and guest-assignment tables; development, test, and container validation require that single migration head.

## Rollback

- Application rollback remains compatible while revision `0009` is present; downgrading to `0008` removes guest records and links and therefore requires a verified environment-specific backup and separate data-recovery approval.

## Known Limitations

- This first delivery child provides the authenticated data and API contract only; the Guest Bank page and show-assignment controls remain in ordered children #45 and #46.
